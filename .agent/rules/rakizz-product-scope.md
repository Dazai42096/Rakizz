Rakizz is an Android-first study-focus system.

Primary actors:
- Student
- Parent
- Admin

MVP includes:
- authentication
- study materials repository
- assignments and deadline tracking
- AI-generated quizzes from uploaded materials
- parent-configurable blocking policies
- Android usage monitoring and app-blocking flow
- reporting dashboard

Do not add:
- iOS app
- payments
- school SIS/LMS integrations
- chat
- browser extensions
- unnecessary gamification
