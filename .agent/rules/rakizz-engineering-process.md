Before substantial coding:
1. produce an implementation plan
2. list files to create or update
3. list risks
4. wait for approval if the task affects architecture or project structure

Engineering requirements:
- production-grade naming
- tests for core logic
- no fake implementations
- no unrelated file rewrites
- keep changes small and reviewable
- create README/setup notes for each app or service
- do not silently change stack decisions
